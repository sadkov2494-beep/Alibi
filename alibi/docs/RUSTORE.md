# Публикация в RuStore

## APK

Сборка release APK выполняется через EAS Build (профиль `production`, формат `apk`).

## Описание для RuStore (краткое)

**Название:** Алиби

**Краткое описание (до 80 символов):**
Детективная головоломка: одна история, три дела, найди настоящую Маску.

**Полное описание:**

«Алиби» — мобильная детективная игра-головоломка в духе классических «закрытых комнат» и вечеринок с тайной.

Вы получаете черные приглашения с фиолетовой печатью и расследуете одну большую историю «Фиолетовый ужин». В каждом деле нужно изучить подозреваемых, улики, временную шкалу и доску расследования, собрать логическую цепочку и назвать виновного и способ преступления.

Особенности:
- одна связанная сюжетная кампания из трёх дел;
- логические загадки без угадывания наугад;
- подсказки трёх уровней;
- можно получить подсказку за просмотр рекламы;
- сохранение прогресса на устройстве.

Если любите детективы, загадки и неожиданные повороты — попробуйте разоблачить настоящую Маску.

**Категория:** Игры → Головоломки / Казуальные

**Возраст:** 12+
